# Mi chuleta de Python

## Los 8 conceptos

- **string** = texto entre comillas. Python lo escribe tal cual, sin calcular.
  Ej: "6 * 7" escribe 6 * 7

- **variable** = un cajón con nombre donde guardo un dato. Nombre a la izquierda del =, dato a la derecha.
  Ej: nota_tributario = 7.5

- **f-string** = texto con una f delante que mete dentro el valor de las variables entre llaves.
  Ej: print(f"Mi media es {media}")

- **función** = una acción: nombre y, entre paréntesis, lo que le doy. Como LARGO o REDONDEAR en Excel.
  Ej: round(7.666, 2) da 7.67

- **lista** = una fila de datos entre corchetes. Cada uno tiene posición, empezando en 0.
  Ej: destinos = ["Bolonia", "Lisboa"]   destinos[0] es "Bolonia"

- **bucle (for)** = repetir una tarea con cada
